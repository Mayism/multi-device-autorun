# 数字银行前端模板

基于 Vue 3、TypeScript 和 Vite 的数字银行前端模板，使用 Vant 构建移动端界面，配合 Vue Router、Pinia 和浏览器端 Mock 接口组织页面与业务流程。所有账户、交易和金额均为演示数据，不连接真实银行系统。

## 功能

- 登录、会话保持和路由访问控制。
- 首页资产概览、账户列表、账户详情和交易流水。
- 模拟转账、金额校验、余额变更和转账回执。
- 信用卡切换、账单与额度展示、模拟还款和权益入口。
- 财富持仓、产品展示与风险提示。
- 消息分类、未读状态、一键已读和个人中心。
- 加载、空数据、错误提示及重试状态。

## 安装与启动

需要 Node.js 22.18 及以上的 22.x 版本，或 Node.js 24.12 及以上版本。

解压后，在解压位置执行以下命令进入项目并启动：

```bat
cd digital-bank-credit-channel
npm ci
npm run dev
```

浏览器访问 http://127.0.0.1:5175 。

登录表单已预填演示信息：手机号 13800138000，密码 123456。业务数据保存在当前页面的内存中，刷新后恢复为初始演示数据。

## 构建与预览

```bat
npm run build
npm run serve
```

构建结果输出到 dist 目录，预览地址为 http://127.0.0.1:4175 。在手机或 WebView 中访问时，使用设备可访问的电脑局域网地址替换 127.0.0.1。
