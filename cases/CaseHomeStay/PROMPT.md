# 提示词

请对当前 HarmonyOS ArkUI 民宿工程完成一多适配，使首页、全部房型页和发现页的瀑布流能够根据窗口宽度正确切换列数。

具体要求：

1. 在 SM 手机宽度下，以下三个瀑布流均保持每行 2 列：
   - 首页“推荐房型”列表；
   - 点击“查看更多”进入的“全部房型”列表；
   - 点击底部“发现”进入的游记/笔记列表。
2. 在 MD 中等宽度（包括折叠屏展开态）下，上述三个瀑布流均调整为每行 4 列。
3. 布局必须响应窗口尺寸变化，使用工程已有或 ArkUI 合适的断点/窗口宽度机制实现；不要根据具体设备名称判断，也不要使用固定物理像素模拟断点。
4. 保留现有卡片内容、间距、滚动、点击、导航和预订等业务行为。确保现有的 `recommend_water_flow`、`all_room_water_flow`、`notes_water_flow` 及其子项 ID 继续有效。
5. 不要修改或新增测试代码，不要修改 `build`、`.hvigor`、`oh_modules` 等生成目录，只修改实现该适配所需的业务源码。

完成后请检查三个页面在 SM 和 MD 宽度下的列数，并确保工程能够正常编译、页面交互没有回归。
